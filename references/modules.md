# 问题模块与触发线索

以下是选题提示，不是已发现的问题或强制问询目录。只有事实支持或明确的信息缺口才生成公司问题。

| 模块 | 可观察线索 | 追问和证据方向 |
|---|---|---|
| 业务与行业 | 模式复杂、增长与行业背离、关键产品贡献变化 | 业务流程、终端需求、竞争格局、订单与收入勾稽 |
| 收入与回款 | 期末集中确认、验收节点模糊、应收增长超过收入、第三方回款 | 合同履约、交付验收、期后回款、退货、截止性及核查覆盖 |
| 成本与利润 | 毛利率背离同行或自身结构、费用异常 | 产品/客户拆分、售价成本桥接、成本完整性、可比口径 |
| 资产与现金流 | 存货或合同资产增长、现金流持续背离利润、减值不足线索 | 库龄、期后销售、减值参数、资金用途与流水核验 |
| 客户供应商 | 高度集中、新增大客户、共用地址/人员、购销重合 | 交易实质、关联关系、终端销售、定价、替代性和持续性 |
| 股权与治理 | 突击入股、控制权变动、代持或特殊权利线索 | 出资来源、历史沿革、协议清理、控制权、治理有效性 |
| 关联交易与独立性 | 资金往来、业务重叠、共享资源、担保 | 关系穿透、交易必要性与公允性、整改及运行证据 |
| 知识产权与研发 | 共有/受让/许可核心专利、前雇主争议、研发资本化、研发人数差异 | 权属链、职务成果、授权范围期限、核心产品收入映射、研发项目台账、费用归集 |
| 软件与数据 | 开源组件、第三方数据、算法或软件许可依赖 | 许可证义务、软件物料清单、商业化限制、数据来源授权及适用监管核验 |
| 法律合规 | 许可缺口、处罚、诉讼、环保或劳动争议 | 事实时间线、主管机关材料、影响量化、整改和持续合规 |
| 募投与持续经营 | 扩产与产能利用率不符、新业务跨度、融资依赖 | 项目可行性、订单支撑、资金测算、审批、敏感性分析 |
| 港股披露与适合上市 | 业务可持续性、合规记录、控制及关联交易、特殊路径线索 | 申请文件披露、适用规则核验、保荐尽调依据及整改有效性 |
| 后续轮次 | 回复回避问题、统计口径变化、证据覆盖不足 | 原问题与回复逐项映射、差异说明、量化补证和核查边界 |

知识产权专题额外核对：
- 区分申请中、授权、有效、失效及地域范围，不能以数量直接推导技术先进性。
- 区分拥有知识产权、获得许可和未侵犯第三方权利，三者不可相互替代。
- 对诉讼记录核实程序阶段，不把起诉等同败诉；对禁令、赔偿及核心产品影响作条件化提问。
- 技术来源、关键人员、委托/合作研发、开源义务与主营收入对应；不推定必须拥有某类专利方可上市。
