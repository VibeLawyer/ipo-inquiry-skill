# 市场与来源策略

本文件是检索导航，不是现行法规汇编。每次执行核验具体规则和版本，不固化数值门槛。

| 市场 | 首选官方来源 | 核验方向 |
|---|---|---|
| A股通用 | 中国证监会 csrc.gov.cn；上交所 sse.com.cn；深交所 szse.cn；北交所 bse.cn | 发行注册、审核规则、信息披露、上市条件及适用指引 |
| 沪深主板 | 对应交易所官方规则和项目审核公开文件 | 板块定位、选定上市标准、业务与财务稳定性、独立性 |
| 科创板 | 上交所、证监会 | 科创属性、技术与研发、核心资产、适用上市标准 |
| 创业板 | 深交所、证监会 | 板块定位、创新与成长、适用标准与行业范围 |
| 北交所 | 北交所、证监会；必要时全国股转系统 neeq.com.cn | 申报主体前置条件、挂牌期间事项、创新特征与适用标准 |
| 港股主板/GEM | hkex.com.hk及其官方规则站；披露易 hkexnews.hk；证监会 sfc.hk | 对应上市规则、申请人指南、公开指引/决定、招股文件、适合上市及保荐尽调 |
| 跨境及A+H | 上述来源，按事项补充境内有关主管部门官方来源 | 境外上市备案、数据跨境、股权架构、外资准入、两地披露口径差异 |

执行方法：
1. 从官方规则目录进入具体正文，核实版本和生效日期；不把搜索摘要作为条文原文。
2. 港股先确认主板/GEM、申请人类别及适用特殊章节（如生物科技、特专科技、不同投票权、第二上市等）；这些是检索候选，不意味着公司适用。先验证路径，再提出资格相关问题。
3. 对A股公开问询/回复，记录公司、交易所、板块、轮次、文件日期、原件链接和定位。对港股仅使用公开申请版本、招股书、上市决定或公开监管材料，不声称获取保密意见函。
4. 可先检索近24个月可比案例，再因样本不足扩展；说明样本范围，不称少数案例为全面统计或最新统一要求。
5. 香港与内地财务报表口径、会计准则和上市测试须分别识别。对境内背景港股申请人，境内合规事实与香港上市要求分开论证。
6. 最终引用给出可打开的官方URL与具体定位；链接、条款、日期未经核验不得补全猜测。
